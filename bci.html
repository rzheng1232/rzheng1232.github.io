Brain-Computer Interface & Robotic Arm Control

Domain: Robotics, BCI, Signal Processing, ML
Technologies: Python, Digital Signal Processing, Machine Learning Classification
Organization: SIGRobotics @ UIUC

Some of the work I've developed as part of the BCI project team lead for SIGRobotics.

The goal of the SIGRobotics BCI team is to develop a silent-speech interface using EMG signals from jaw muscles. We bought the ArdEEG biosensing shield for Arduino for around $200 and our first goal was to develop a robust data collection platform to record EMG data alongside other data modalities (like video). The system captures multi-channel EMG data from surface electrodes, processes it through a digital signal processing (DSP) pipeline — including filtering, windowing, and feature extraction — and feeds the result into an ML classifier that maps muscle activation patterns to discrete arm commands. The classified output is then streamed to the robot controller for low-latency execution.

The focus has been on keeping the full pipeline real-time: minimizing latency from sensor capture through classification to actuation, while maintaining classification accuracy across different users and electrode placements.
